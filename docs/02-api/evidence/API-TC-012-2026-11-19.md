# API-TC-012 验证证据

- 执行日期：2026-11-19
- 数据源：`https://playapi.info`
- 凭据：有效凭据通过请求头传递；不记录密钥

## 无效日期

请求参数包含 `since=not-a-date`。

- HTTP 400
- 错误码：`invalid_param`
- 错误：`since must be a date YYYY-MM-DD`

## 超出每页条数

请求 `/new` 时传 `per=101`，其余日期参数有效。

- HTTP 200
- 服务将 `per` 规范为 100，并返回 100 条记录。
- Token 成本：2

## 不存在的应用

使用虚构应用 ID 请求 `/app`。

- HTTP 404
- 错误码：`not_found`
- 错误：`App not found in our Google Play database`
- Token 成本：1

## 无效类别

请求 `/new` 时传入 `category=INVALID_CATEGORY`，其余日期参数有效。

- HTTP 200
- 返回 `total=0` 和空结果数组；接口不返回参数错误。
- Token 成本：2

无效日期请求响应未返回 Token 计费字段，因此不记录该请求成本。
