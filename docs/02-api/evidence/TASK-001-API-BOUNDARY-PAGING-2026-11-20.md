## 分页终止与访问上限

小范围日期查询的分页元数据符合 `pages = ceil(total / per)`：四个边界日/类别组合的末页分别返回 14、30、25、99 条，与各自第一页的 `total` 和 `per=100` 相符。`page=2&per=100` 对大范围查询成功返回 100 条。

对 `since=2025-01-01&until=2026-11-20&category=GAME_PUZZLE&per=100` 的验证结果：

| 请求页 | HTTP | 返回条数 | 响应 `total` | 响应 `pages` |
|---:|---:|---:|---:|---:|
| 1 | 200 | 100 | 74,580 | 100 |
| 2 | 200 | 100 | 74,580 | 100 |
| 100 | 200 | 100 | 74,580 | 100 |
| 101 | 400 | 0 | — | — |

当 `total > 10,000` 时，响应 `pages` 封顶为 100，仍可读取第 100 页，第 101 页不可访问。完整性判定规则：仅当同一轮分页的元数据一致且 `total <= 10,000` 时，才可按该轮 `total`、`per` 和末页实际条数确认终止；`total > 10,000` 时明确判为不可完整读取，整体失败，不得将前 10,000 条作为完整列表。不同请求轮次的 `total` 不可互相替代。对可访问范围内仍须检查页序、每页条数和请求失败，不能只凭 HTTP 200 假定完整。
