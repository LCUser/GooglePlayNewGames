## 日期列表、分类与排序

- `GET /api/v1/new?since=2026-11-04&until=2026-11-12&per=20`：HTTP 200；返回 `total=47181`、`per=20`；结果包含多个非游戏类别。
- 列表记录字段：`id`、`title`、`url`、`icon`、`developer`、`category`、`installs`、`rating`、`free`、`price`、`currency`、`released`、`updated`、`removed`、`removed_seen_at`。
- 样本 `released` 为 UTC ISO 8601 时间戳，结果默认按时间从新到旧。
- 同日起止日期查询 `since=2026-11-04&until=2026-11-04&per=1` 返回 `released=2026-11-04T23:59:55Z`，证明该 UTC 日范围包含该日记录。
- `category=GAME_CASINO&per=5` 返回 5 条且类别均为 `GAME_CASINO`；`category=GAME` 返回 0 条。
- `per=100` 返回 100 条。`page=2&per=5` 返回第二页数据，样本 ID 与第一页样本不重合；没有验证整个结果集无遗漏。
- `/new` 官方规格中的 `per` 范围为 1–100，每个查询最多可翻到第 10,000 条；`sort` 支持 `released`。
- 对相同日期范围分别请求 `sort=released&order=asc` 与 `sort=released&order=desc`，两者首条记录相同且日期为当天最新；本次未观察到 `order` 改变结果顺序。
- `/new` 每个请求成本为 2 Token。

## 详情与国家可用性

- `GET /api/v1/app?id=<脱敏样本>`：HTTP 200；详情对象包含 `id`、`url`、`title`、`title_lang`、`summary`、`description`、`recent_changes`、`status`、`installs`、`rating`、`pricing`、`category`、`content_rating`、`developer`、`released`、`updated`、`version`、`android_min`、`media`。`recent_changes` 样本为 null。成本 1 Token。
- 对应新上架样本请求 `/availability` 返回 HTTP 404、错误码 `not_found`，消息说明该应用没有国家数据。成熟应用样本返回 HTTP 200、`countries_count=242`、`worldwide=true`、`countries=null`，并说明不存储逐国家列表。成本 1 Token。
- 因此，国家可用性接口不能为所有新应用证明 US 可用。
