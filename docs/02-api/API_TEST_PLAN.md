# API 验证计划

- 文档编号：API-PLAN-001
- 状态：阶段 2 执行中

## 验证范围
- 接口可用性与认证
- 请求参数及参数组合
- 返回字段、类型、空值和数据质量
- 分页基本行为
- 分类筛选行为
- 日期范围与排序行为
- 错误响应、超时和异常情况
- 目标类别、日期范围与列表返回行为

## 约束
只做 API 验证，不写正式业务代码，不开发正式 iOS 页面。测试凭据不得写入仓库；请求和响应证据必须脱敏。
产品无搜索功能；不测试或实现搜索。
