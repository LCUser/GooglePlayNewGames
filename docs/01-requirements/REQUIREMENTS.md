- 文档编号：REQ-DOC-001
- 版本：V0.4 草案
- 状态：待 Gate 1 审核
- 更新时间：2026-11-19
- 说明：此前讨论中的产品意图仅作为需求输入；最终功能以 API 实测和用户批准的需求基线为准。

## 产品定位
- 目标用户：普通玩家
- 使用背景：工作需要
- 默认市场：美国（US）Google Play
- 界面语言：英语

| 需求 ID | 名称 | 描述 | 优先级 | 状态 | 验收标准 | API 证据 |
|---|---|---|---|---|---|---|
| REQ-001 | 新游列表 | 展示美国 Google Play 首次上架时间距当前日期 7 至 15 天的游戏列表 | 必须 | 待 Gate 1 审核 | AC-REQ-001 | 待阶段 2 验证 |

## 验收标准草案
### AC-REQ-001 新游列表
- 列表只包含美国（US）Google Play 的游戏。
- 列表只包含首次上架时间距当前日期 7 至 15 天的游戏，同时包含第 7 天和第 15 天。
- “当前日期”按照用户设备本地时区计算。
- 列表按首次上架时间从新到旧固定展示。
- 界面不提供排序按钮。
- App 完全启动时自动刷新数据；App 从后台回到前台时不自动刷新。
- 具体展示字段以阶段 2 实测 API 返回为准，不新增 API 未返回的信息。
- 没有符合条件的游戏时，只显示英文提示 `No games found`。
- 数据加载失败时，只显示英文提示 `Unable to load games`，不做其他处理。

### AC-REQ-002 游戏详情
- 用户点击新游列表中的游戏条目进入对应游戏的详情。
- 具体展示字段以阶段 2 实测 API 返回为准，不新增 API 未返回的信息。
- 详情中不提供跳转 Google Play 的入口。

## 首版非目标
- 用户登录
- 社交功能
- 付费功能
- 跨设备同步
- App Store 上架
- 分类筛选
- 国家/地区筛选
- 日期筛选
- 搜索
- 排序
- 收藏
- 分享
- 跳转 Google Play
- 新游通知
- 多语言支持

除用户明确批准的需求外，不得增加其他内容或功能。

## 阶段 1 待确认问题
无。

## 阶段 2 待验证事项
- API 是否提供可验证的 Google Play 首次上架日期。
- API 是否支持美国（US）市场数据。
- API 是否支持获取距当前日期 7 至 15 天的数据，或可通过返回数据准确计算。
- API 返回的列表与详情字段、类型、完整性和稳定性。
- API 是否支持按首次上架时间从新到旧获取数据，或可通过返回数据准确排序。
