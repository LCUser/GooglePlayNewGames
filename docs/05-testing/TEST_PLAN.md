## 覆盖范围

- 日期逻辑：第 7/15 天包含边界、本地日历、UTC 跨日、DST。
- 数据服务：认证配置、固定 HTTPS 主机、响应解码、已完成的双类别分页聚合逻辑，以及当前列表首次加载的单次 `GAME_CASUAL` 第 1 页请求契约。
- UI 与生命周期：英文列表、空/失败状态、详情导航、完全启动时仅请求一次、后台回前台不刷新及成功响应 JSON 的控制台输出。
- 本地交付：Xcode 16.1、iOS 16.0 部署目标、Swift 6.0 语言模式、本机运行及凭据不提交。
